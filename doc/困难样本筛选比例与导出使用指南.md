# 困难样本筛选比例与导出使用指南

本文介绍如何在配置中直接控制困难样本筛选比例，并批量导出困难样本原图。

## 一、在配置中设置 Top 比例

在你的 YAML 配置（例如 `configs/nih14_wkversion.yaml`）中加入：

```yaml
post:
  ensemble: true
  aggregate: true
  skip_if_exists: false
  difficult_ratio: 0.1   # 按比例筛选困难样本，10%
```

说明：
- `difficult_ratio`（0~1]，若设置则优先按比例筛选（Top-R）。
- 未设置时，聚合器会使用分位数模式（`--entropy_q/--disagree_q`）筛选。

运行：
```bash
python -m src.scripts.run_from_config --config configs/nih14_wkversion.yaml
# 仅做后处理（不重训）：
python -m src.scripts.run_from_config --config configs/nih14_wkversion.yaml --post_only
```

结果：
- 困难样本清单：`<out_dir>/difficult.csv`
- 集成预测：`<out_dir>/ensemble_preds.csv`

## 二、聚合器参数说明（多标签）
脚本：`src/scripts/aggregate_difficult_multilabel.py`

- 比例模式：`--top_ratio 0.1` 选取前 10%
- 分位模式：`--entropy_q 0.8 --disagree_q 0.8`（若未指定比例时生效）
- 难度得分：默认 `0.7×熵排名 + 0.3×分歧排名`（分歧为 Jaccard 的 1-均值）

## 三、导出困难样本图片
脚本：`src/scripts/export_difficult_images.py`

示例：
```bash
# 从 NIH 烟雾测试产物导出困难样本原图
python -m src.scripts.export_difficult_images \
  --difficult_csv outputs/nih14_smoke/difficult.csv \
  --meta_csv rawig/NIH/nih_manifest.csv \
  --out_dir exports/nih14_smoke_difficult \
  --img_root rawig/NIH \
  --id_col image_id --path_col image_path

# 先抽样 100 张快速核验
python -m src.scripts.export_difficult_images \
  --difficult_csv outputs/nih14_smoke/difficult.csv \
  --meta_csv rawig/NIH/nih_manifest.csv \
  --out_dir exports/nih14_smoke_difficult_sample \
  --img_root rawig/NIH \
  --id_col image_id --path_col image_path \
  --limit 100
```

注意：
- 若困难 CSV 中已经包含 `image_path` 且路径有效，可不提供 `--meta_csv`。
- 若 `image_path` 是相对路径，可用 `--img_root` 拼接根目录。

## 四、常见问题
- Q：为什么输出的困难样本数接近 10%？
  - A：当设置了 `difficult_ratio` 时，聚合器会严格按比例从高到低选取。
- Q：想用分位阈值而不是比例？
  - A：移除配置中的 `difficult_ratio`，并通过 `entropy_q/disagree_q` 控制。
- Q：如何只导出部分困难样本做抽样检查？
  - A：使用 `--limit N` 参数。
